# 验证记录

## 环境

| 项 | 值 |
|---|---|
| 浏览器 | Chromium（Playwright bundled, `chromium-1243`），headless |
| GL 后端 | SwiftShader（`--use-angle=swiftshader --enable-unsafe-swiftshader`）——纯软件光栅化 |
| WebGL 版本 | `WebGL 2.0 (OpenGL ES 3.0 Chromium)` |
| 视口 | 1280×720，内部渲染分辨率 768×432（Render Scale 0.6） |
| HDR 路径 | 启用（`EXT_color_buffer_float` 可用） |
| 采集方式 | Playwright 页面截图 + `gl.readPixels` 统计 |

## 结果

无 `pageerror`，无 `console.error`，6 个 shader program 全部编译链接成功，帧计数持续递增。
各调试视图的像素统计互不相同，说明每一级都在真实写入数据：

| 视图 | 平均亮度 | 唯一颜色数（上限 3000） |
|---|---|---|
| 01 final（ACES + sRGB） | 95.7 | ≥3000 |
| 02 G-Buffer · Albedo | 77.9 | 1521 |
| 03 G-Buffer · Normal | 155.1 | ≥3000 |
| 04 G-Buffer · Depth（线性化） | 136.4 | 142 |
| 05 G-Buffer · Rough/Metal | 33.7 | 197 |
| 06 SSAO | 251.7 | 154 |
| 07 SSR Hit Mask | 77.5 | 1963 |

解读：

- Albedo 唯一色数低（1521）符合预期——材质是纯色 + 程序化网格，没有贴图。
- Depth 只有 142 个灰度级，因为它是 8 bit 输出且被归一化到 `far*0.35`；结构可辨（地面渐变 + 球体轮廓），见 `docs/screenshots/04-gbuffer-depth.png`。
- Rough/Metal 只有一个通道有明显变化（大多数材质粗糙度低 → R 接近 0），所以偏暗。
- SSAO 平均 251.7 说明遮蔽只集中在接触区域（最暗像素 77），而不是全屏压暗——这是正确的行为，AO 只乘进环境项。
- SSR 掩膜 1963 个颜色说明命中分布有结构（地面镜面倒影 + 球面掠射命中），不是噪声。

## 开发中定位并修复的三个真实缺陷

### 1. SSAO 视空间深度比较方向写反

现象：平面被判定为 100% 遮蔽，AO 全黑，金属球的环境项被乘成 0，镜面球变成纯黑球。

原因：视空间 Z 是负数，「更靠近相机」意味着 Z **更大**。第一版按「Z 越小越远」的直觉写成
`scenePos.z <= samplePos.z - bias`，恰好把「采样点在表面前方」误判成被遮蔽。

修复：改为 `scenePos.z >= samplePos.z + bias`，并把 `smoothstep` 距离权重换成「采样球外直接剔除 + 命中计 1」，避免软权重把遮蔽强度整体压低。

### 2. SSR 凸面镜反射自己

现象：镜面球下半部分出现带锯齿的黑色尖角状块，边缘有噪点。

定位：给 SSR 加了命中掩膜调试视图（现在保留为下拉框第 7 项），确认黑色区域是「命中」而非「未命中」——射线投影回屏幕后落在球体自身的像素上，采到的是球体背面的暗色。

修复：G-Buffer 增加 RGBA8 的 `objectId` 附件，命中点与起点同 ID 直接丢弃；同时加背面法线拒绝、最小命中距离、6 次二分细化、掠射角加权，锯齿与噪点消失。

### 3. 深度可视化全黑

现象：`04-gbuffer-depth` 第一次采集时平均亮度 0、唯一颜色 1（整屏纯黑）。

原因：近平面 0.1 / 远平面 120 时，非线性深度在可见范围内几乎全部贴近 1.0，`pow(1-d, 1.6)` 恒为 0。

修复：按 `2nf / (f + n - z(f - n))` 线性化，再除以 `far*0.35` 归一化。

## 已知局限

- **帧率不代表 GPU 表现**：截图环境是 SwiftShader 软件光栅化，32 采样 SSAO + 52 步 SSR 在 CPU 上约 1–2 fps。真实 GPU 上该分辨率不是瓶颈，但本仓库没有 GPU 实测数据，不写未测过的数字。
- **SSR 是单趟屏幕空间追踪**：屏幕外信息不存在，粗糙表面只能靠淡出而不是多次采样模糊。
- **没有阴影**：AO 只作用于环境项，方向光没有 shadow map，因此没有硬阴影与接触阴影。
- **环境光是解析近似**：金属球看不到旁边的球体，只有天空 / 虚拟地面 / 柔光箱。
- 未做移动端 / 低端 GPU 的分级降质（只有渲染分辨率缩放一个开关）。
